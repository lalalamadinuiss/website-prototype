📖 About

This project is a responsive portfolio-style website designed to showcase information, projects and contact details through a clean and minimal dark interface.
The website was created to practice the fundamentals of frontend development and gain hands-on experience with HTML and CSS.

✨ Features

- Responsive layout
- Dark modern UI
- Navigation menu
- Hero section
- About section
- Portfolio section
- News section
- Contact form
- Styled input fields and buttons
- Image-based content

 🛠 Tech Stack

- HTML5 — semantic page structure
- CSS3 - layout, styling and responsive design
- Flexbox - element positioning
- Git/GitHub -  project version control

🎯 Learning Goals

The main purpose of this project was to practice:

- HTML page structure
- CSS styling
- Flexbox layout
- Positioning elements
- Working with forms
- Creating responsive interfaces
- Organizing a frontend project
